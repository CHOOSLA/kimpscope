# KimpScope — 김치 프리미엄 RAG

업비트와 해외 거래소의 코인 가격 차이(김치 프리미엄, 김프)를 계산하고, **그 차이가 왜 생겼는지**를 거래소 공지와 입출금 상태를 근거로 설명하는 RAG 서비스입니다.

- 배포: https://kimpscope.onrender.com (무료 서버라 잠들어 있으면 첫 접속에 30초~1분 걸립니다)
- 과제: SSAFY AI 코어 프로젝트 2회차 — RAG 지식 서비스
- 셀프 체크리스트: 27개 중 26개 통과 ([결과](docs/checklist/RESULTS.md)). 남은 1개는 상호 체크리스트 미작성

## 한눈에 보기

- **김프는 계산합니다.** 업비트 원화가 ÷ (해외 USDT가 × 원/달러 기준환율) − 1. 가격과 환율은 질문할 때마다 새로 조회합니다.
- **원인은 문서로 설명합니다.** 입출금 중지, 유의종목 지정, 네트워크 점검 같은 공지를 찾아 답변의 문장마다 근거 번호를 붙입니다.
- **현재 값은 색인하지 않습니다.** 벡터 저장소에 넣는 순간 지난 값이 되기 때문입니다. 문서 속 옛 숫자를 현재 값처럼 답하지 못하게 막습니다.

## 요구사항을 어떻게 충족했나

필수 기능(F2001~F2012)과 선택 기능(F2013~F2016)을 모두 구현했습니다.

| 요구사항 | 구현 |
| --- | --- |
| 항목 데이터와 색인 (F2001·F2002) | 업비트 원화 마켓 298개 코인을 한 문장씩 만들어 색인. 다시 색인해도 개수가 늘지 않음 |
| 문서 수집 (F2003~F2005) | 질문에서 검색어를 뽑고(프롬프트 1), 관련 문서를 골라(프롬프트 2) 잘게 나눠 색인. 같은 질문은 다시 수집하지 않음 |
| 검색과 답변 (F2006~F2008) | 선택 코인 정보는 항상 근거 1번. 답변은 근거만 쓰고, 실제로 인용한 근거만 화면에 표시 |
| 서비스 기능 (F2009~F2012) | 코인별 대화 분리, 김프 시세표, 조건 탐색, 처리 중·오류·투자 유의 안내 |
| 선택 기능 (F2013~F2016) | 직접 만든 화면(HTML·CSS·JS), MMR 검색, RAG 전후 비교, 출처 종류 표시 |
| 비기능 (NF2001~NF2007) | 응답 30초 이내, 키는 환경변수로만, 화면에 내부 정보 미노출, 모듈 분리, 호출 간격 준수, 출처 기록 |

요구사항별 구현 위치와 확인 결과는 [요구사항 정의서](docs/REQUIREMENTS.md)에 있습니다.

## 동작 방식

```
질문 ─▶ 검색어 추출 ─▶ 관련 문서 선별 ─▶ 색인 ─▶ 검색 ─▶ 답변 생성 ─▶ 인용 검사
                                                  ▲
                         질문 시점의 시세·김프·입출금 상태 (색인하지 않음)
```

- 문서: 빗썸 공지(입출금 중지, 유의종목 등)와 공식 문서 7건(업비트 API 문서, bitcoin.org, ethereum.org, 해외송금·트래블룰·법인 참여에 관한 정부 보도자료)
- 가격: 업비트 + 해외 거래소(바이낸스, 막히면 OKX 등), 환율: 공개 기준환율

자세한 설계(컬렉션, 청크 설정, 프롬프트, 겪은 문제)는 [RAG 파이프라인 설계문서](docs/RAG_DESIGN.md)에 있습니다.

## 실행

```powershell
copy .env.example .env              # 이미 .env가 있으면 덮어쓰지 마세요. OPENAI_API_KEY를 넣습니다
pwsh -File scripts/run.ps1 -Setup   # 처음 한 번: 가상환경과 의존성 설치
pwsh -File scripts/run.ps1          # http://127.0.0.1:4173
```

처음 실행하면 화면 위쪽의 **데이터 색인**을 한 번 누른 뒤 질문합니다. macOS/Linux는 `python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt && sh scripts/run.sh`입니다. 환경변수 전체 목록은 [설계문서 10절](docs/RAG_DESIGN.md#10-모듈과-환경변수)에 있습니다. 테스트는 `.\.venv\Scripts\python.exe -m pytest -q`로 돌립니다(72개, 외부 호출 없음).

## 한계

- 입출금 상태와 공지는 **빗썸 기준**입니다. 업비트 데이터는 API 키가 필요해 쓰지 못했고, 답변에도 빗썸 기준이라고 밝힙니다.
- 코인별 설명 문서가 아직 적습니다. 공지가 연결된 코인은 298개 중 40여 개입니다.
- 환율은 하루 단위 고시 환율이라, 고시 이후의 환율 변동이 김프에 섞입니다.
- 교육용 시연 서비스입니다. 투자 조언이 아닙니다.
