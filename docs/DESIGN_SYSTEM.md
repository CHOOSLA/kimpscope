# KimpScope Design System 2 · 2026-10-22

## 조사와 판단

- 김프런: https://kimprun.com 실제 접속은 DNS 오류. 현재 화면을 확인했다고 주장하지 않는다. 공개 README https://github.com/Hojip-Kim/KimpRun_BE_JAVA 에서 4개 거래소 시세 집계, 프리미엄, 공지 집계, 메타데이터, 커뮤니티 구조를 확인했다. 해당 저장소는 독점 라이선스이므로 소스/디자인 복제 없이 목적과 정보 흐름만 참고한다.
- Kraken Pro 공식 UI 가이드: https://support.kraken.com/articles/kraken-pro-trading-interface-guide — 시장 선택과 핵심 수치를 상단 ribbon에 유지하고 세부 기능을 widget에 배치. 플랫폼 상태를 드러냄. 이를 가격/문서 상태의 분리 표시로 적용한다.
- IBM Carbon Data Table: https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines — 검색·필터·정렬을 표 toolbar에 배치, 일관된 행 높이, 필요한 정보의 점진적 노출. 이를 시세표/문서 표에 적용한다.

## 신뢰감을 만드는 규칙

1. 최신성: 실제 수신 시각을 표시한다. 가격, 환율, 문서 시각은 다른 값이다. 연결됨만으로 최신이라고 표시하지 않는다.
2. 출처: 문서 유형·원문·수집 시각·인용 번호를 드러낸다. 샘플과 실제 원문은 혼합하지 않는다.
3. 수치: 우측 정렬, tabular-nums, 단위는 열 제목에 표시. 미수신/오래된 값은 0으로 바꾸지 않는다.
4. 상태: LIVE/연결 중/지연/미연결을 문자로 구분한다. 색만으로 의미를 전달하지 않는다.
5. 절제: 영웅 문구, 장식 그래프, 녹색 그라데이션 카드 제거. 선택·상태·변화에만 색을 사용한다.

## 구조

헤더: 서비스/마켓/관심/공지/데이터 상태.
상단 compact ribbon: 평균 프리미엄, BTC, 최대 차이, 리서치 상태.
좌측 시장표 + 우측 선택 코인 상세. 아래 문서와 코인별 리서치.
자연어 탐색은 조건 해석 결과를 보여주고 실제 조건에 맞는 메타데이터만 표시.
연결되지 않은 기능에 가짜 성공을 표시하지 않는다.

## 검증 범위

김프런 현재 화면 미확인. 선택한 공식 레퍼런스 원문 확인. 사용자 취향의 최종 판단은 실제 재설계 화면에서 받는다.
