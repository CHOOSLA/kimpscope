원자료: [`evaluation.json`](evaluation.json). 2026-10-22 PC 실연동 검증 때(`WINDOWS_VERIFICATION.md`) 실제 생성 모델 API로 같은 질문을 두 번 실행한 기록이다. 파일에는 날짜·모델 필드가 없다. 한 번은 근거 없이 질문만, 한 번은 전체 RAG 그래프로. 판정은 2026-10-23에 Claude가 원자료의 답변을 인용 원문과 문장 단위로 대조해 적었다.

당시 검색 후보는 공식 문서 4건(업비트 API 문서 2, bitcoin.org, ethereum.org)과 항목 메타데이터였다. 김프 도메인으로 좁히기 전의 질문 세트다. 김프 질문(현재 김프, 원인 설명)은 운영 실행 결과를 [체크리스트 결과](checklist/RESULTS.md)에 따로 남겼다.

## 이 비교에서 바꾼 것

- Q5의 실패로 "현재 값 질문에는 문서 속 숫자를 쓰지 않는다"는 규칙을 만들었다. 지금은 질문 시점의 시세·상태 스냅샷을 근거로 만들고, 그 근거를 인용하지 않은 답은 폐기한다([LIVE_EVIDENCE.md](LIVE_EVIDENCE.md)).
- 인용 번호가 실제 근거에 있는지는 규칙으로 검사하지만, 문장 내용이 그 근거에 있는지는 검사하지 않는다. 이번 판정은 수동 대조다. 문장 단위 자동 대조는 남은 과제다.
