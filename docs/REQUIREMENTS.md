# 요구사항 정의서 — KimpScope (김치 프리미엄 RAG)

작성 2026-10-23. 원문은 「AI코어프로젝트_2회차_요구사항정의서.pdf」(23쪽)이고, 아래 표의 ID와 충족 조건은 원문을 따른다. "구현"과 "확인" 칸은 이 저장소의 코드와 [셀프 체크리스트 결과](checklist/RESULTS.md)(2026-10-23 운영·로컬 실행)를 기준으로 적었다. 확인하지 않은 것은 확인으로 적지 않았다.

## 1. 서비스와 도메인

| 항목 | 내용 |
| --- | --- |
| 서비스 | KimpScope. 국내(업비트) 원화가와 해외 USDT가의 차이인 김치 프리미엄(김프)을 계산하고, 그 차이가 생긴 이유를 거래소 공지·입출금 상태 근거로 설명한다 |
| 사용자 질문 예 | "지금 비트코인 김프는?", "이 코인만 김프가 높은 이유는?", "최근 입출금이 중지된 적 있어?" |
| RAG가 필요한 이유 | 김프 수치는 계산으로 얻는다. 그 원인(입출금 중지, 경보, 네트워크 점검)은 문서에만 있고 모델 지식으로 답하면 틀린다 |
| 위험 도메인 | 해당(금융, 가상자산 투자 정보). 투자 조언을 대신하지 않는다는 안내를 붙이고, 매수·매도 판단과 가격 예측은 답하지 않는다 |
| 배포 | https://kimpscope.onrender.com (Render 무료 플랜) |

### 도메인 조건 충족 근거

| 원문 조건 | 충족 근거 |
| --- | --- |
| 항목 메타데이터 약 100건 이상 | 업비트 KRW 마켓 298건(`/v1/market/all?is_details=true`, 키 불필요). 2026-10-23 실측 시 시세 없는 종목 0, 유의 6·주의 15 |
| 항목별 외부 문서 | 빗썸 공지(코인 심볼로 연결, 본문 371~5,523자 21건), 공식 문서 7건(업비트 API 문서 2, bitcoin.org, ethereum.org, 김프의 제도적 배경을 다룬 정부 보도자료 3), 항목 자체 문서(마켓 메타데이터) |
| 근거가 필요한 질문 3개 이상 | 아래 대표 질문 6개 |
| 출처·이용 조건 | [SOURCES.md](SOURCES.md)에 출처별 주소·키·호출 정책·이용 조건을 기록. 확인하지 못한 조건은 미확인으로 남김 |

검토 후 제외한 출처: CoinGecko(약관이 데이터 저장·가공을 금지해 벡터 색인과 충돌), 위키백과(코인 문서 보유율 실측 26%, 김프 3% 초과 코인 5개는 모두 문서 없음), 업비트 공지·입출금 현황(API 키 필요, 발급 불가).

### 대표 질문

| # | 질문 | 시험하는 것 |
| --- | --- | --- |
| 1 | 지금 비트코인 김프는 몇 %인가? | 실시간 값 세 개(국내가·해외가·환율)를 질문 시점에 계산해 기준 시각과 함께 답하는가 |

## 5. 범위에서 뺀 것과 한계

- 업비트 공지와 입출금 현황은 수집하지 않는다(API 키 필요, 신분증 문제로 발급 불가). 입출금 상태와 공지는 빗썸 기준이며 답변에 그렇게 밝힌다.
- 원/달러는 고시 환율이다(수출입은행 키 발급 전에는 Frankfurter). 고시 이후의 환율 변동분이 김프에 섞인다.
- 빗썸 공지 목록 API는 최근 20건만 준다. 수집을 시작한 뒤의 공지만 쌓인다.
- 원문 지정 UI는 Streamlit이지만 F2013을 선택해 HTML·CSS·JS 화면으로 만들었다.
